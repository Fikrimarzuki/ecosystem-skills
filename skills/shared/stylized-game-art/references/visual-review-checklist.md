# Visual review checklist

Run in the actual game, with screenshots attached to the report.

- [ ] Silhouette reads at gameplay size (squint test) for every species / character option.
- [ ] Front, side and back views are the same character; colours and accessories survive in each view.
- [ ] The same configuration is recognisable in every visual style, side by side.
- [ ] Palette is coherent: no stray colours, ramps hue-shift consistently, outlines follow one rule.
- [ ] Pixel art: one pixel density, integer scaling, no blur, positions snapped.
- [ ] 3D: no visible primitive seams where a continuous form was intended; shading steps clean; no z-fighting.
- [ ] Idle, walk, sit and task animations are distinct and smooth at play speed; reduced motion respected.
- [ ] Furniture and props share the style's shape language and scale relative to the character.
- [ ] Lighting / weather / theme variants keep the character readable.
- [ ] Desktop and phone framing: nothing important clipped or occluded; the face is visible in close-ups.
- [ ] Budgets measured and stated (and labelled as real-device or headless).
- [ ] Every non-original asset has a licence record; prototypes are labelled as prototypes.
